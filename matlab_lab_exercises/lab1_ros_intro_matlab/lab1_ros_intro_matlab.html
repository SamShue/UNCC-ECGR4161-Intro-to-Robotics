Objective

In this MATLAB-based Lab 1, you will set up the full ROMI toolchain and validate end-to-end communication using ROS 2 topics.

The setup process is the same as the standard Lab 1 for robot bring-up (Arduino, Pi image, WSL2, ROS 2, VS Code, sync script). The core difference is that your laptop-side logic test will publish from MATLAB (ROS Toolbox) instead of a Python node.

Required Materials

  • Romi32U4 Control Board (included in the Romi kit)
  • Micro USB cable
  • Laptop (Windows preferred)
  • Raspberry Pi 4B
  • ≥ 32GB MicroSD card (+ adapter if needed)
  • 6x AA batteries
  • MATLAB with ROS Toolbox

Background

System Architecture

  • Raspberry Pi 4B: high-level ROS 2 runtime and hardware bridge process.
  • Romi 32U4: low-level motor and sensor interface over I2C.
  • Laptop: development workstation and command publisher.

ROS 2 enables these devices to communicate via topics. In this MATLAB version of the lab, your laptop publishes command topics using ROS Toolbox.

Topics Used in This Lab

  • /leds with std_msgs/Int16MultiArray, data = [red, yellow, green].
  • /wheel_pwm with std_msgs/Int16MultiArray, data = [left_pwm, right_pwm].

Important: During validation, use conservative PWM magnitudes (for example, +/-80 to +/-120), and always send a final stop command [0, 0].

Procedure

To fully set up the robot and toolchain, follow all steps below:

  1. Assemble the robot (if using a personal kit)
  2. Install and configure Arduino IDE for the Romi32U4
  3. Prepare the Raspberry Pi image
  4. Install ROS 2 in WSL2
  5. Install MATLAB and ROS Toolbox
  6. Install/configure VS Code and sync workflow
  7. Validate end-to-end operation with MATLAB publishing

Step 1.0: Assemble the Robot

IMPORTANT: This step is only required for students using their own Romi kit. If using a provided lab robot, proceed to Step 1.1.

If needed, use the ROMI assembly guide from the course materials before continuing.

Step 1.1: Install Arduino IDE

  • Download Arduino IDE from Arduino's website.
  • Install the version for your operating system.

Step 1.2: Configure Arduino IDE for Romi32U4

Install Windows Drivers

  1. Download and extract the A-Star Windows Drivers.
  2. Right-click a-star.inf and click Install.

Add Pololu A-Star Board Support

  1. Open Arduino IDE and go to File > Preferences > Settings.
  2. Add this URL in Additional boards manager URLs:

https://files.pololu.com/arduino/package_pololu_index.json

  1. Install Pololu A-Star Boards in Boards Manager.
  2. Select Pololu A-Star 32U4 as your board.

Install Romi32U4 Library

  1. Go to Sketch > Include Library > Manage Libraries.
  2. Search and install Romi32U4.

Step 1.3: Program the Romi

Flash RomiRPiSlaveDemo.ino to the Romi board.

Step 2: Raspberry Pi Setup

  1. Download the class Pi image: Class Pi Image.
  2. Install Raspberry Pi Imager.
  3. Flash the image to your SD card (Raspberry Pi 4, Use Custom, then select SD card).

Step 3: ROS 2 in WSL2

  1. Open PowerShell as administrator.
  2. Run wsl --install
  3. Run wsl --install -d Ubuntu-22.04
  4. Install ROS 2 Humble Desktop + development tools by following the official docs.

Add ROS setup to your bashrc:

echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc

Set WSL networking mode to Mirrored and allow Hyper-V inbound traffic:

Set-NetFirewallHyperVVMSetting -Name '{40E0AC32-46A5-438A-A0B2-2B479E8F2E90}' -DefaultInboundAction Allow

Clone the class repository in WSL:

cd ~
mkdir -p ros2_ws/src
cd ros2_ws/src
git clone -b lab1 https://github.com/UNCC-Embedded-Lab/ROMI-ROS2.git

Step 4: Install MATLAB and ROS Toolbox

  1. Install MATLAB through your university MathWorks portal.
  2. Sign in with your charlotte.edu credentials when MATLAB launches.
  3. In Add-On Explorer, install or verify ROS Toolbox.
  4. Optional check in MATLAB Command Window: ver

Step 5: Install and Configure VS Code

  1. Install VS Code.
  2. Install the WSL extension.
  3. Connect to WSL using Ubuntu and open your Linux home directory.

Step 6: Build and Sync Workspace to Pi

In WSL:

cd ~/ros2_ws
colcon build --symlink-install
source ~/ros2_ws/install/setup.bash

Sync code to the Pi:

cd ~/ros2_ws/src/ROMI-ROS2
./scripts/sync_to_pi.sh

On the Pi, confirm package installation:

ros2 pkg prefix romi_base

Step 7: End-to-End MATLAB Validation

Hardware Assembly and Power

  • Mount Raspberry Pi on the Romi header in the correct orientation.
  • Install 6 AA batteries and power the robot from the battery pack.
  • Wait for boot. Join Wi-Fi AP Romi-XXXX (password: romi32u4).

Start the Bridge Node on the Pi

ssh student@192.168.4.1
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/setup.bash
export ROS_DOMAIN_ID=0
ros2 run romi_base astar_bridge

Create and Run MATLAB Publisher Script

Create romi_matlab_setup_test.m:

% romi_matlab_setup_test.m
% MATLAB ROS 2 publisher test for ROMI Lab 1

clear;
clc;

% Must match ROS_DOMAIN_ID used on the Pi terminal.
setenv('ROS_DOMAIN_ID', '0');

% Create ROS 2 node and publishers.
node = ros2node('/matlab_setup_test_node');
ledPub = ros2publisher(node, '/leds', 'std_msgs/Int16MultiArray');
pwmPub = ros2publisher(node, '/wheel_pwm', 'std_msgs/Int16MultiArray');

% Create messages.
ledMsg = ros2message(ledPub);
pwmMsg = ros2message(pwmPub);

% Helper function call wrapper.
sendCmd = @(ledArray, pwmArray, pauseSec) localSend(ledPub, ledMsg, ledArray, pwmPub, pwmMsg, pwmArray, pauseSec);

disp('Starting MATLAB ROMI setup test...');

% GREEN + stop
sendCmd([0, 0, 1], [0, 0], 1.5);

% YELLOW + forward
sendCmd([0, 1, 0], [80, 80], 2.0);

% GREEN + stop
sendCmd([0, 0, 1], [0, 0], 1.5);

% RED + reverse
sendCmd([1, 0, 0], [-80, -80], 2.0);

% GREEN + final stop
sendCmd([0, 0, 1], [0, 0], 1.5);

disp('Test complete.');

function localSend(ledPub, ledMsg, ledArray, pwmPub, pwmMsg, pwmArray, pauseSec)
    ledMsg.data = int16(ledArray);
    pwmMsg.data = int16(pwmArray);

    send(ledPub, ledMsg);
    send(pwmPub, pwmMsg);

    pause(pauseSec);
end

Run in MATLAB Command Window:

romi_matlab_setup_test

Optional Topic Checks

ros2 topic list
ros2 topic echo /leds
ros2 topic echo /wheel_pwm

Observe the Output

The Romi LEDs should match the commanded sequence and the wheels should move forward, stop, reverse, and stop. This confirms your end-to-end communication path from laptop MATLAB publisher to ROS 2 topic transport to Pi bridge to low-level I2C hardware control.
